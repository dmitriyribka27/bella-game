# Bella game

Техническая основа для мобильной игры. Игровая концепция ещё не утверждена.

## Текущее состояние

- `docs/index.html` — проверочная страница для Safari и GitHub Pages, не игра.
- Нет зависимостей, платных API или привязки к Netlify.
- Публикация ещё не подключена.
- PWA, офлайн и игровые сохранения ещё не реализованы.

## Публикация

После создания репозитория и отправки файлов:
Settings → Pages → Deploy from a branch → main → /docs → Save.

В дальнейшем сборка игры должна попадать в `docs/`.
Все пути к ресурсам должны учитывать размещение в подпапке репозитория.
Не размещать в публичном репозитории секреты или личные материалы без согласования.

## Работа с телефона

На ПК: Settings → Connections → Control this PC → Set up / Add.
Подключить iPhone через предложенное сопряжение, используя тот же аккаунт
ChatGPT и рабочее пространство.
На iPhone: ChatGPT → Codex (или Remote) → подключённый ПК → нужный чат.
Компьютер должен оставаться включённым, с открытым приложением и интернетом.

GitHub Pages обслуживает опубликованную игру независимо от состояния ПК.
Работа агента расходует лимиты текущего плана ChatGPT/Codex.
