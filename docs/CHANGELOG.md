# Тихая бухта — 0.4.0

- У книжной лавки Цитеры появился расширенный изометрический интерьер по согласованному референсу: сама лавка, личная гостиная с диваном, телевизором и кошачьими игрушками, а также спальня с душевой кабиной за шторкой.
- Новый интерьер открывается при касании книжной лавки и из списка мест. Есть переключатели «Весь дом», «Лавка», «Гостиная» и «Спальня» для просмотра комнат крупнее без обрезания общего рисунка.
- Картинка хранится отдельным оптимизированным WebP и загружается лишь при входе в лавку, чтобы не замедлять карту острова. Исходный интерьер оставлен в репозитории для отката.
- Книжные заказы, начисление монет и опыта, маршруты котов и существующие сохранения не изменены. Отдельные механики личных комнат добавим позже.

## Ограничения

Карта — статичный рисунок: изменение оформления зданий на ней и дополнительные интерьеры будут реализованы отдельно. Уже существующая книжная лавка доступна. Коты пока отрисовываются поверх карты, без отдельной маски перекрытия деревьями. После публикации проверить жесты и масштаб на настоящем iPhone.
